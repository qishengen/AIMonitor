# PXA 像素动画格式 (v1)

面向 git 分享的**纯文本**像素画/像素动画格式：可直接在代码仓库/文本编辑器里预览，diff 友好，解析简单。

## 特性
- 纯文本、UTF-8、每帧是 ASCII 字符画 → **不装任何工具就能看**
- 自描述：尺寸/帧率/循环/名称都在头部
- 版本化（`;PXA v1`），可向后兼容扩展
- 黑白色（`#`=已绘制，`.`=空白），与 AIMonitor 设备一致；预留调色板扩展位

## 文件示例

```
;PXA v1
;W=8 H=4 F=2 FPS=12 LOOP=1
;NAME=heart
;---- FRAME 0 ----
.#....#.
##.##.##
#######
.#######.
;---- FRAME 1 ----
........
..##.##.
.#######.
.#######.
```

## 语法
| 行 | 含义 |
|---|---|
| `;PXA v1` | 魔数 + 版本（首行） |
| `;W=<宽> H=<高> F=<帧数> FPS=<帧率> LOOP=<0|1>` | 尺寸与播放参数（单行，空格分隔 K=V） |
| `;NAME=<名字>` | 可选，动画名 |
| `;---- FRAME <序号> ----` | 帧分隔符 |
| 其他行 | 像素行：**恰好 W 个字符**，`#`=已绘制(黑)，`.`=空白(白)；共 H 行/帧 |

- `;` 开头的行均为元数据/注释，解析器忽略空行。
- 像素行不足 W 字符时按缺省为 `.`；超出截断（宽容解析）。
- 位序：逐像素从左到右，字符 `#` 对应设备显示 LSB 位（bit0=行最左）。

## 与设备/工具链的关系
- `.pxa` ⇄ XBM(LSB) ⇄ `.anm`（设备二进制，固定 128×64，每帧 1024B）可互转。
- 编辑器（`动画编辑器.html`）支持**导入/导出 PXA**。
- Python 工具：`G:\AIMonitor\Code\host\pxa.py`（`to_pxa` / `parse_pxa`）。
- 上传设备前先切到 128×64(设备) 画布再导/存。

## 分享约定
- 文件名建议 `<名字>.pxa`，放入仓库任意目录即可。
- 保持每帧宽高一致、首行魔数准确，其他工具/人即可直接复用。
