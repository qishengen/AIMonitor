像素动画编辑器 - 需求规格说明书
1. 项目概述
一个单页 Web 应用，允许用户在可调节尺寸的画布上逐像素绘制，并管理多帧动画。支持导入/导出多种格式，包括图片、GIF 和 C 语言数组，并内置黑白位图压缩及位序配置功能。目标用户为嵌入式开发者和像素画创作者。

2. 运行环境
纯前端实现，单个 HTML 文件（内嵌 CSS 和 JS），无需构建工具或服务器。

支持现代浏览器：Chrome 90+、Firefox 88+、Edge 90+、Safari 14+。

响应式设计，移动端触摸支持。

3. 数据模型
3.1 帧数据结构
frames: Array<{ pixelData: number[][] }>

pixelData 为 gridSize × gridSize 的二维数组，每个元素为 24 位颜色值（0xRRGGBB）。

白色背景定义为 0xFFFFFF，黑色为 0x000000。

3.2 历史记录
每帧独立维护撤销/重做栈：historyStacks: Array<{ undoStack: Array<number[][]>, redoStack: Array<number[][]> }>。

最大栈深度：80 步。

3.3 全局状态
变量	类型	说明
gridSize	number	当前画布尺寸（宽高相等）
cellSize	number	画布显示单元格像素大小（固定 512px 总宽度）
currentFrameIdx	number	当前编辑帧索引
currentColor	number	当前画笔颜色（0xRRGGBB）
showGrid	boolean	是否显示网格
bwMode	boolean	恒为 true（黑白模式，彩色模式已移除）
zoomLevel	number	画布缩放级别 (1~5)
msbFirst	boolean	位图位序：true=MSB（高位对应左像素），false=LSB
refOpacity	number	参考图透明度 (0~1)
fps	number	动画播放帧率 (1~30)
loop	boolean	播放循环
4. UI 布局
整体采用垂直弹性布局，居中显示，最大宽度 900px。

4.1 布局顺序（自上而下）
标题栏：应用名称 + 画布尺寸下拉选择器（16×16 / 32×32 / 64×64 / 64×32 / 128×64(设备)）。

导入栏：导入图片（→帧）、导入 C 数组、设置参考图。

画笔栏（独占一行，内部元素分散对齐）：

颜色预设：黑、白（橡皮擦）。彩色模式已移除，仅黑白。

操作栏：撤销、重做、清空帧、反色、网格开关、选择工具。

画布区域：

缩放控制条（滑块 + 1:1 复位）。

可滚动容器内包含：

参考背景图层（<img>，默认隐藏）。

像素画布（<canvas>，512×512 CSS 尺寸，内部像素渲染）。

参考图透明度控制条（导入后显示）。

帧操作按钮行（独立居中）：添加帧、复制帧、删除帧、上移帧、下移帧。

帧列表行（最大宽度 520px，居中）：

横向滚动缩略图，每个缩略图 56×56px。

当前帧高亮。

播放控制栏（最大宽度 520px，居中）：

播放/暂停按钮、FPS 滑块、循环复选框。

导出栏（居中）：

导出 PNG、JPEG、BMP、GIF 动画。

导出 C 数组（当前帧 / 全部帧，仅黑白字节位图）。

位序切换按钮（MSB / LSB）。

设备控制面板（新增）：串口连接、上传动画、发送当前帧、设备播放/停止、流式预览、状态查询、日志区。

状态栏：坐标、已绘制像素数、当前帧/总帧数、黑白模式、当前位序。

操作提示。

5. 功能需求
5.1 画布与绘制
5.1.1 像素绘制
使用鼠标左键拖拽绘制当前颜色，右键拖拽擦除（变为白色）。

拖动过程中使用 Bresenham 直线算法插值，保证快速移动时线条连续。

触摸屏支持单指绘制。

5.1.2 颜色管理
点击预设颜色块或使用取色器设置当前颜色。

橡皮擦本质是白色。

黑白模式下，非白色预设颜色自动隐藏，取色器强制为黑色。

5.1.3 网格显示
默认显示浅灰色网格线，可通过按钮切换。

5.1.4 画布缩放
通过滑块（1x~5x，步进 0.25）或 Ctrl+滚轮 调节缩放。

缩放仅影响 CSS transform，不改变像素数据。

缩放后画布容器可滚动。

5.2 帧与动画
5.2.1 帧管理
添加帧：在末尾创建空白帧。

复制帧：复制当前帧并插入其后。

删除帧：删除当前帧（至少保留 1 帧）。

移动帧：上移或下移当前帧。

点击缩略图切换当前编辑帧。

5.2.2 动画播放
循环播放：从当前帧开始，按顺序以设定 FPS 播放。

播放时可切换帧，但暂停后保持当前帧。

不循环时播放到最后一帧停止。

5.3 撤销/重做
每帧独立历史栈，深度 80。

操作（绘制、清空帧、反色）前自动保存快照。

快捷键：Ctrl+Z（撤销）、Ctrl+Y（重做）。

5.4 参考背景图
支持导入图片作为半透明参考图层，覆盖整个画布。

透明度滑块实时调节（0%~100%）。

可清除参考图。

参考图不参与任何导出或像素操作。

5.5 黑白模式
固定为黑白模式（彩色模式已移除），所有非白色绘制强制变为黑色。

颜色预设仅黑、白、橡皮擦。

影响 C 数组导入导出：支持字节级 bit 压缩。

图片导入仍接受彩色图，但导入时自动二值化。

5.6 导入
5.6.1 图片导入
支持 JPG、PNG、GIF。

静态图片：进入「导入预览」——等比缩放居中，可拖动移动、滚轮缩放，选择「填充(全局阈值)」「自适应(局部对比，按邻域均值保留内部明暗细节)」或「轮廓(边缘 Sobel)」二值化，应用后写入当前帧。

GIF 动画：内置 LZW 解码 + 逐帧合成（支持部分帧更新、透明、处置方式 0/1/2/3），等比适应缩放生成多帧，阈值二值化；播放用全局 FPS。

5.6.2 C 数组导入
格式识别：

十六进制字节数组（如 0xFF, 0x0F），根据当前位序解析（仅黑白）。

自动提取宏定义 WIDTH、HEIGHT、FRAME_COUNT，若与当前画布不符则提示用户选择是否调整画布尺寸。

导入前清除所有 #define 行，避免宏数字污染像素数据。

三维数组自动拆分为多帧。

5.7 导出
5.7.1 图片导出
PNG / JPEG (0.92 质量) / BMP (24位) 导出当前帧。

BMP 兼容标准格式，从下至上扫描行，4 字节对齐。

5.7.2 GIF 动画导出
将全部帧以当前 FPS 速度编码为 GIF89a 动画（无限循环）。

内置 GIF 编码器（全局调色板，LZW 压缩）。

5.7.3 C 数组导出
当前帧：const unsigned char bitmap[WIDTH * HEIGHT / 8] = { ... };

全部帧：const unsigned char animation[FRAME_COUNT][WIDTH * HEIGHT / 8] = { ... };

每个字节表示 8 个像素（1=黑，0=白）。

位序由 msbFirst 决定：MSB 时字节高位对应左像素，LSB 时低位对应左像素。

文件头部包含 #define WIDTH、#define HEIGHT、#define FRAME_COUNT（多帧时）。

导出为 .h 文件，可直接下载。

5.8 设备联动（AIMonitor）
通过 Web Serial API（Chrome/Edge，需 localhost/https 打开）连接 ESP8266。

内置 AIMonitor JSON 协议客户端：命令编解码（JSON 明文 + 原始二进制数据体），支持 show/frame/up_chunk 等带数据指令的 size 字段。

控制界面按钮：
- 连接/断开 + 波特率选择（默认 921600）。
- 上传动画：构造 .anm（ANM0 头 + fps + 帧数 + 每帧 1024B XBM），走 up_begin/up_chunk/up_end 分块上传，CRC32(zlib) 校验。
- 发送当前帧：show 命令即时在设备直显当前帧。
- 设备播放/停止：play / stop。
- 流式预览：stream_start/frame/stream_end，按编辑器 FPS 实时推流播放全部帧。
- 状态查询：ping/status/list，回显固件版本、FS 容量、动画列表。
- 日志区显示设备回包（ack/nack/progress 等）。

帧映射：任意画布尺寸等比缩放居中到设备 128×64；128×64 画布为 1:1 原生映射。

6. 交互详情
6.1 快捷键
快捷键	功能
Ctrl + Z	撤销
Ctrl + Y	重做
Ctrl + 滚轮	缩放画布
6.2 鼠标/触摸
左键拖拽：绘制

右键拖拽：擦除（或长按触摸）

滚轮 + Ctrl：缩放

6.3 选择/移动模式
进入：工具栏「🔲 选择」切换。

框选：左键按下开始框选，拖拽扩大选区，抬起结束（单击 = 选中 1 格）。

移动：在已选区域内左键按下并拖拽，像素实时跟随光标移动（实时预览），抬起落下。

取消选择：在选区外单击会开始新框选；右键单击可清空当前选择。

7. 技术实现细节
7.1 GIF 编解码
内嵌独立的 GIF 解码器（支持多帧、LZW 解压、透明色）和编码器（全局颜色表生成、LZW 压缩、动画控制）。

无任何外部依赖。

7.2 位图 bit 打包
导出/导入时按行遍历像素，每 8 个像素压入 1 字节。

位序控制：

MSB：byte |= (1 << (7 - bitPos))

LSB：byte |= (1 << bitPos)

最后不足 8 位的部分自动补零。

7.3 渲染性能
画布宽度固定 512px（cellSize = 512 / gridWidth），高度随画布高宽比自适应；128×64 画布为 512×256。

使用 image-rendering: pixelated 保持清晰边缘。

帧缩略图使用离屏 Canvas 绘制，实时更新。

8. 非功能性需求
可维护性：所有代码内嵌于单一 HTML，结构清晰，注释完整。

兼容性：移动端自适应，缩略图尺寸在窄屏自动缩小。

用户体验：操作有 Toast 提示，重要操作有确认对话框。

9. 文件清单
pixel-editor.html：包含完整 CSS、HTML 和 JavaScript（GIF 编解码器 + 主程序）。
